# 2026-01-27

## 今日学んだこと

### ターミナルでMarkdownをリアルタイム監視表示する方法

ターミナルを左右分割して、片側でClaude Code、もう片側でタスクリストをリアルタイム表示したいという課題に取り組んだ。

#### glow -p のページャーモードはループをブロックする

`glow -p` の `-p` オプションはlessのような全画面ページャーを起動するため、whileループ内で使うとユーザー入力待ちでブロックされてしまう。fswatch自体はiCloudドライブ上のファイル変更も正しく検出できていたが、ページャーが原因でリアルタイム更新が動作しなかった。

#### ファイル監視ツールの使い分け

- **fswatch**: ファイルシステムイベントを検出。iCloudドライブでも動作する
- **entr**: シンプルな記法 `echo "$f" | entr -c command` でファイル変更時にコマンド実行
- **watch**: 定期的にコマンドを実行して全画面表示。macOSは `brew install watch` が必要

最終的に `watch -c -n 1 "glow \"$f\""` で全画面リアルタイム表示を実現した。

#### watchコマンドでスペースを含むパスの扱い

iCloudドライブのパス（`Mobile Documents`）のようにスペースを含む場合、watchコマンドでは二重クォートが必要:

```bash
watch -c -n 1 "glow \"$f\""
```

単に `watch -c -n 1 glow "$f"` だと、スペースで引数が分割されてエラーになる。

### Zellijとエディタのキーバインド競合

nano（Ctrl+O で保存）やvim（Ctrl+S）などのキーバインドがZellijに取られてしまう問題がある。解決策として、ターミナル内エディタではなくObsidianで直接編集する運用に切り替えた。Obsidianは自動保存があるため、watchで監視すればリアルタイム反映される。
